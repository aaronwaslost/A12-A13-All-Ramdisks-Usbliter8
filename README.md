Supported Versions

A12 Devices

- iOS 18.0 – 18.7.9

A13 Devices

- iOS 18.0 – 27.0 Beta

«Mounting: These ramdisks are intended to be mounted using the iOS 16.4+ mount method. Community implementations of this method can be found on GitHub.»

«Important: Do NOT, absolutely DO NOT, open issues, contact me, or complain that these ramdisks do not mount on iOS versions below 18. They are not designed to support earlier iOS versions, and reports regarding unsupported versions will be ignored.»

Purpose

This repository was created to help developers understand A12 and A13 ramdisk development, particularly mounting "/mnt2" and related research.

The files are intended as a reference for learning, experimentation, and personal research. If these ramdisks help you understand how they work or assist you in developing your own tools or workflows, then they have served their purpose.
